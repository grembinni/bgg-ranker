# Milestone v0.9: Core Loop

**Status:** ✅ SHIPPED 2026-05-25
**Phases:** 1–3.1 (4 phases, 1 inserted)
**Total Plans:** 13

## Overview

Core ranking-and-sync loop is feature-complete. Users can load their BGG collection, rank games through head-to-head comparisons across a bell-curve distribution, and sync ratings back to BGG. Persistence, authentication, dirty-game tracking, and drag-and-drop reordering all work. Display polish (cover art, upset callouts) and Firebase production deploy are deferred to subsequent phases.
