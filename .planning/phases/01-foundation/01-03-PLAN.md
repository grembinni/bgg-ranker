  <action>
    Create `scripts/smoke-test-dev.sh` as a bash script. Set the shebang `#!/usr/bin/env bash` and strict mode `set -euo pipefail`.

    The script reads credentials exclusively from environment variables:
    - `BGG_USERNAME` — required (script fails immediately if unset, per `${BGG_USERNAME:?BGG_USERNAME required}`)
    - `BGG_PASSWORD` — required (same pattern)
    - `VITE_BGG_API_BASE` — optional, defaults to `http://localhost:5173/bggapi`

    The script tests three sections in order:

    Section 1 — Collection read with 202 poll loop (Pitfall C1):
    Poll up to 8 times with 3s sleep between attempts. On each attempt:
    - `curl -si "${BASE}/xmlapi2/collection?username=${USERNAME}&own=1&subtype=boardgame"`
    - Extract HTTP status from response headers
    - If 200: log first 200 chars of body, echo "[OK] Collection read succeeded", break loop
    - If 202: echo "BGG queued — waiting 3s...", sleep 3, continue
    - Any other status: echo "[FAIL] Unexpected status $STATUS", exit 1
    - If all 8 retries exhausted without 200: echo "[FAIL] Timed out", exit 1

    Section 2 — Login (extract sessionId):
    - POST to `${BASE}/login/api/v1` with JSON body `{"credentials":{"username":"${USERNAME}","password":"${PASSWORD}"}}`
    - Log HTTP status (not the password value)
    - In dev: Vite proxy relays Set-Cookie from BGG; extract sessionid from Set-Cookie header
    - If Set-Cookie not present, try JSON body field `sessionId` (fallback for future compatibility)
    - If session ID extraction fails: echo "[FAIL]", exit 1
    - If successful: echo "[OK] Got session ID (${#SESSION_ID} chars)" — log LENGTH only, never the value

    Section 3 — Write one rating (WARN on failure — undocumented endpoint):
    - POST to `${BASE}/api/geekrating` with form-urlencoded body `objectid=174430&objecttype=thing&rating=7`
    - Send `Cookie: sessionid=${SESSION_ID}` header
    - Log HTTP status and first 200 chars of response body
    - If 2xx: echo "[OK] Write rating succeeded"
    - If non-2xx: echo "[WARN] Write returned $WRITE_STATUS — verify geekrating endpoint format (undocumented, Assumption A1)"
    - DO NOT exit 1 on write failure — write endpoint is [ASSUMED] (per D-14 note and planning guidance)

    End of script: echo "=== Smoke test complete ===" and exit 0.

    Make the script executable: `chmod +x scripts/smoke-test-dev.sh`

    The script must NOT hard-code any credentials, BGG usernames, or passwords. Game ID 174430 (Gloomhaven) is a safe test target for the write path.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Vite proxy | Browser sends all /bggapi/* requests to Vite server; Vite forwards to BGG; no credentials in URL |
| Vite proxy → boardgamegeek.com | Server-side HTTPS request; BGG session cookie extracted and rewritten for localhost |
| smoke script → BGG | Credentials from env vars; session token never logged as value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `scripts/smoke-test-dev.sh` credential logging | mitigate | Script logs `${#SESSION_ID}` (length) not `$SESSION_ID` (value); `BGG_PASSWORD` never echoed; enforced in acceptance criteria |
| T-03-02 | Information Disclosure | Vite proxy forwards cookies to localhost | accept | Dev-only; localhost is not accessible externally; `cookieDomainRewrite: 'localhost'` scopes cookie to localhost |
| T-03-03 | Spoofing | CORS proxy leaks to third party | mitigate | Vite proxy target is hardcoded to `boardgamegeek.com` only; no dynamic target routing; request forwarding is to BGG exclusively |
| T-03-04 | Information Disclosure | `BGG_USERNAME` / `BGG_PASSWORD` in shell environment | mitigate | Script uses `${VAR:?}` pattern — fails fast if unset; never commits `.env.local`; `.gitignore` excludes `.env.local` (established in Plan 01) |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages in this plan — vite.config.ts edit uses existing installed packages only; smoke script is pure bash |
</threat_model>
