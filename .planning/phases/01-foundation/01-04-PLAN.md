<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SPA → Firebase Function | Browser sends fetch() to Function URL; CORS headers added by Firebase `cors: true` option |
| Firebase Function → boardgamegeek.com | Server-side HTTPS via Node.js `node:https`; no browser involvement; BGG credentials forwarded in appropriate headers |
| Function response → SPA | Only `sessionId` (session token) returned as JSON; no Set-Cookie relay; safe headers only for non-login paths |
| smoke script → Firebase Function | Credentials from env vars; session token logged as length only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | `proxy/functions/src/index.ts` — Set-Cookie relay | mitigate | Function extracts `sessionid` value from Set-Cookie and returns as `{ sessionId }` JSON body only (D-07). Set-Cookie header is never forwarded to SPA. Verified in acceptance criteria. |
| T-04-02 | Elevation of Privilege | Firebase Function publicly accessible | accept | Function forwards to BGG only; no Firebase resources accessed; BGG session token validated by BGG on each write; Function has no admin capabilities. Low-value target for attackers. |
| T-04-03 | Information Disclosure | `X-BGG-Session` header in Function logs | mitigate | Firebase Functions logs are private to project; executor should review GCP IAM to ensure only project owner has log access. Session token in logs is acceptable risk for solo dev project. |
| T-04-04 | Information Disclosure | `scripts/smoke-test-prod.sh` credential logging | mitigate | Same pattern as dev script: `${#SESSION_ID}` (length), `BGG_PASSWORD` never echoed, credentials only from env vars. |
| T-04-05 | Spoofing | Firebase Function endpoint domain | accept | Firebase Function URL is HTTPS with Google-managed cert. BGG session token sent only to known Firebase Function URL set in `FIREBASE_URL` env var. |
| T-04-06 | Tampering | `.firebaserc` project ID | mitigate | `.firebaserc` committed with placeholder `YOUR_FIREBASE_PROJECT_ID`; actual value substituted at deploy time; wrong project ID causes `firebase deploy` to fail with clear error. |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | `firebase-functions@^7.0.0` and `firebase-admin@^13.0.0` both Approved in Package Legitimacy Audit (RESEARCH.md); `firebase-tools@15.x` installed globally — executor must verify version matches audit before installing. |
</threat_model>
