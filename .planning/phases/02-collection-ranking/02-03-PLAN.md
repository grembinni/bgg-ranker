# Plan 02-03: Vertical Slice — Comparison Loop UI (Pick, Skip, Refresh, Counter, Persistence)

## Phase Goal

**As a** BGG user, **I want to** enter my BGG username and rank my owned games head-to-head with progress saved locally, **so that** I can build a ranked list of my collection that reflects my actual preferences.

<objective>
Deliver the second vertical slice that completes Phase 2: the user sees two game cards with name + year + rank position, clicks "Pick this game" on the one they prefer, the ratings update via `applyUpset`, the counter increments by one in both session and total counts, the next pair appears immediately, and the rankings are saved to localStorage. The user can also Skip the current pair (it's appended to the in-memory queue and a fresh pair appears) or trigger Refresh (which calls `redistribute` and resets all ratings while preserving relative order). On page reload, the user sees the username entry view; re-entering the same username surfaces the continue-or-refetch prompt; choosing "Continue ranking" lands them back in the comparison view with their accumulated `comparisonsTotal` intact and a fresh pair selected. This plan ONLY adds the two new React components and replaces the comparison placeholder in `App.tsx`. The store actions `pick`, `skip`, and `refresh` were already implemented in Plan 02-02 to satisfy the Wave 0 store tests; this plan wires the UI to them.
</objective>

```typescript
import { useStore } from './store/store'
import UsernameEntry from './components/UsernameEntry'
import CollectionLoading from './components/CollectionLoading'
import ComparisonView from './components/ComparisonView'
import ErrorDisplay from './components/ErrorDisplay'

function App() {
  const view = useStore(s => s.view)

      {view === 'error' && <ErrorDisplay />}

  )
}

export default App
```
