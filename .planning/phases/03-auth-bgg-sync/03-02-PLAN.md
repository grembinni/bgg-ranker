| Boundary | Description |
|----------|-------------|
| SPA → Vite proxy | Proxy intercepts /login/api/v1 response and rewrites body to JSON |
| Proxy → BGG | BGG returns Set-Cookie sessionid; proxy extracts it before browser sees the response |
| Store → bggClient | Store passes sessionId to bggRateGame as X-BGG-Session header; never stored to localStorage |
| localStorage | partialize allowlist never includes sessionId or password |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | Zustand partialize / localStorage | mitigate | sessionId excluded from partialize allowlist; verified by store.test.ts assertion |
| T-03-02 | Information Disclosure | Vite proxy proxyRes handler | mitigate | sessionid extracted from Set-Cookie and returned as JSON body; Set-Cookie header cleared from login response so browser never sees the cookie |
| T-03-03 | Elevation of Privilege | bggRateGame — X-BGG-Session header | mitigate | sessionId sourced only from bggLogin response in Zustand memory; never from URL params or local storage |
| T-03-04 | Spoofing | BGG login endpoint (undocumented) | accept | endpoint confirmed by smoke-test-dev.sh; low risk of spoofing on localhost dev proxy |
| T-03-05 | Denial of Service | Sync loop — bulk writes | mitigate | 200–500ms random delay between each bggRateGame call enforced in startSync loop (SYNC-02) |
