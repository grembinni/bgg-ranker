## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → UsernameEntry | Password enters the component as controlled input state; passed directly to login() — never written to DOM attributes, data-* attrs, or localStorage |
| Component → Store | login() receives (username, password) as call arguments; component holds no reference after the call returns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Information Disclosure | UsernameEntry password state | mitigate | Password is in local React state (useState), not in Zustand store; cleared when component unmounts or user navigates away |
| T-03-07 | Information Disclosure | Form autocomplete | accept | autocomplete="current-password" is standard browser behavior; browser credential manager is not a threat for this use case |
| T-03-08 | Tampering | beforeunload guard | accept | Guard fires on any tab close; cannot be subverted by attacker without already having page control (XSS) — low priority |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages |
</threat_model>
