| SyncingView → Store | Component only calls store actions (cancelSync, reAuthAndResume); never calls bggClient directly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Information Disclosure | SyncingView inline re-auth | mitigate | reAuthPassword is local React state (useState), cleared on component unmount; never written to store or localStorage |
| T-03-10 | Tampering | startSync disabled check | accept | Disabled state is UI-only; store action itself checks sessionId and toSync list defensively |

| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages |
