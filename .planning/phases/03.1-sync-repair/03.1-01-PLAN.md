<objective>
Fix the sync write path so that "Sync to BGG" succeeds in practice.

Three concrete changes:
1. Vite proxy: when `proxySession` is null, construct a fallback Cookie from the `X-BGG-Session` header the client sends (`Cookie: SessionID=<value>`). Currently the proxy strips the header and injects nothing, sending the write request to BGG unauthenticated.
2. bggRateGame: add `ajax=1` to the POST body and log the actual HTTP status + response body on failure so errors are diagnosable.
3. startSync: change the per-write delay from random 200–500ms to a fixed 1000ms.

After this plan, a user who has logged in (proxySession populated) OR who hasn't restarted the dev server (fallback path) will be able to sync successfully.
</objective>

    Current logic:
      proxyReq.removeHeader('x-bgg-session')
      const session = proxySession ?? devSession
      if (session) proxyReq.setHeader('Cookie', session)

    New logic:
      const xBggSession = req.headers['x-bgg-session'] as string | undefined
      proxyReq.removeHeader('x-bgg-session')
      const session = proxySession ?? devSession ?? (xBggSession ? `SessionID=${xBggSession}` : null)
      if (session) proxyReq.setHeader('Cookie', session)
