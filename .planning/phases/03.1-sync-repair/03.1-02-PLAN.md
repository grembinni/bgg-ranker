<objective>
Replace the blunt "clear syncedGameIds on every comparison" pattern with precise dirty-game tracking.

Currently every pick, reorder, or markUnplayed wipes the entire syncedGameIds list, forcing the next sync to re-send ALL games. This plan adds `dirtyGameIds: string[]` to the store and marks exactly the games affected by each action. `startSync` then iterates only the dirty set — a 200-game collection after 5 comparisons syncs 2–10 games, not 200.

`syncedGameIds` is removed. `dirtyGameIds` replaces it as the primary sync-readiness signal.
</objective>
