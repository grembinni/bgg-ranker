# Plan 03.1-02 Summary — Dirty Game Tracking

## What Was Built

Replaced the blunt `syncedGameIds` accumulator with precise `dirtyGameIds` tracking. Every mutation to ratings now marks only the affected games as dirty; `startSync` iterates only that set instead of re-sending the full collection.

## Changes by File

### src/store/store.ts

- **RankingsStateSlice:** Removed `syncedGameIds: string[]`, added `dirtyGameIds: string[]`
- **partialize:** Now persists `dirtyGameIds` (removed `syncedGameIds`)
- **fetchCollection:** Marks all seeded game IDs dirty on initial load (first sync sends everything)
- **pick():** Diffs old vs new `ratings` after `applyUpset`; marks only changed IDs dirty
- **markUnplayed():** Marks the moved game dirty (rating=0 must sync to BGG)
- **reorderRankedList():** Marks all reordered IDs dirty (all ratings change)
- **moveUnplayedToRanked():** Marks all re-ranked IDs dirty
- **refresh():** Marks all rated IDs dirty
- **markGameSynced():** Removes gameId from `dirtyGameIds` instead of adding to `syncedGameIds`
- **startSync():** Snapshots `dirtyGameIds` at start, iterates that copy, updates `syncTotal` to dirty count
- **completeSyncAll():** No explicit dirty-clear needed — `markGameSynced` drains it per game
- **cancelSync():** No `syncedGameIds` to preserve; remaining dirty IDs survive for resume
- **resetForNewUser:** Resets `dirtyGameIds: []` when discarding old rankings

### src/components/ComparisonView.tsx

- Replaced `comparisonsAtLastSync` + `syncedGameIds` + `hasUnsyncedUnplayed` reads with `dirtyGameIds`
- New sync disabled condition: `!sessionId || dirtyGameIds.length === 0`

### src/components/ComparisonView.test.tsx

- Mock store updated: removed `comparisonsAtLastSync`, `syncedGameIds`; added `dirtyGameIds: string[]`
- Tests updated to use `mockDirtyGameIds` as the enabled/disabled signal
- Descriptions updated to reflect dirty-based semantics

### src/App.tsx

- Removed `comparisonsTotal`/`comparisonsAtLastSync` from beforeunload useEffect
- New condition: `dirtyGameIds.length > 0` triggers the unload warning
- Dependency array simplified to `[dirtyGameIds.length]`
