# Phase 4.1 Plan 02 Summary: RankedGridView — 10x10 thumbnail grid with DnD, pagination, image preloading

## One-liner

10-column sortable thumbnail grid using `rectSortingStrategy` DnD, 100-game pages with 50-game shifts, and session-scoped `new Image()` preloading via `useRef<Set<string>>`.

## What Was Built

Created `src/components/RankedGridView.tsx` — the primary new UI deliverable for Phase 4.1. The component renders all ranked games as thumbnail images in a fixed 10-column grid. It is self-contained and ready to be mounted by `App.tsx` in Plan 03.

### Sub-components and hooks

**`SortableGridCell`** (private, module-scoped):
- Uses `useSortable({ id })` from `@dnd-kit/sortable`; spreads `{...attributes} {...listeners}` on the outer div for full-cell drag (no separate handle — Claude's Discretion, CONTEXT.md)
- Protocol-relative thumbnail URLs normalised to `https:` via `normalizeUrl` helper
- `onError` sets `display: 'none'` on the broken `<img>` (T-04.1-01 mitigated — no alt text exposed)
- Gray `bg-gray-100` placeholder div for games without a thumbnail (D-06)

**`RankedGridView`** (default export):
- `sortedFromStore` derived from `Object.entries(ratings).sort((a,b) => b[1]-a[1])` — integer-internal, no division
- `localOrder` optimistic state (`string[] | null`), pattern from `RankedListView`
- `pageOffset` (`useState(0)`) — session-only, not persisted
- `safeOffset` clamp guards against off-end offset after collection changes (Pitfall 4)
- `pageSlice = orderedIds.slice(safeOffset, safeOffset + 100)`
- `handleDragEnd` builds `newFullOrder` by merging reordered page slice back into `orderedIds` (full-list merge, not slice-only — Pitfall 1)
- `preloadedUrls` `useRef<Set<string>>(new Set())` — session-scoped, no re-render on mutation
- `preloadImages` fires inside `useEffect([safeOffset])` — preloads visible 100 + incoming 50; fire-and-forget (D-13)

## Decisions Made

- **Full-cell drag:** No explicit drag handle on grid cells. The entire `aspect-square` cell is the drag target via spread of `{...attributes} {...listeners}`. Standard UX for image grids (Claude's Discretion).
- **Pagination above grid only:** Controls placed above the grid (not below) — cleaner layout given the dense 10-column grid; users orient before scrolling.
- **safeOffset instead of pageOffset for all slice ops:** Prevents "Rankings 251–350 of 240" edge case when collection shrinks while grid is open.
- **preloadImages called for incoming 50 (not 100):** The next page advance will shift by 50 games, so preloading items at `[safeOffset+50, safeOffset+150)` covers the next visible window without over-fetching.
