### Accepted Risks Log

- **T-04.1-02** (Tampering — `reorderRankedList` merge in RankedGridView.tsx): Accepted. Reordering input is constrained to store-owned game IDs and pointer/DnD events only; no free-text, URL, or cross-origin input can enter the merged order. Residual risk: a malicious/buggy `active.id`/`over.id` from dnd-kit internals could theoretically reference an ID not present in `pageSlice` (`indexOf` returns `-1`), but `arrayMove` with a `-1` index is a pre-existing dnd-kit library behavior shared with `RankedListView.tsx` (unchanged pattern) and out of scope for this phase's mitigation — accepted as consistent with the established list-view pattern.
- **T-04.1-SC** (Tampering — supply chain / new installs): Accepted. No new packages were installed in Phase 04.1. `@dnd-kit/*` packages were already present in `package.json` from a prior phase and are reused, not newly introduced.
