## Decisions Made
- Header renders in its own `max-w-6xl mx-auto px-4 pt-8` wrapper as the first child inside App.tsx's `<div className="bg-gray-50 min-h-screen">`, rather than being imported into each view's own container — this was the planner's resolution of the UI-SPEC container discretion item, guaranteeing byte-identical header markup across all four views (success criterion #1).
- Extracted the hamburger state/timer/handler pattern from `ComparisonView.tsx` lines 27-33 verbatim (menuOpen state, 150ms close-delay timer, handleMenuEnter/Leave), adding one new handler (`handleUnplayed`) that follows the identical `setMenuOpen(false)` + action convention as the three existing handlers.
- Added `view` as a new `useStore` selector in Header (not present in the original ComparisonView header block) — required only for the active-icon highlight logic (`view === 'comparison' | 'ranked-list' | 'ranked-grid'`).
