  <what-built>
    A universal Header (hamburger with Sync/Refresh/Unplayed/Logout, session counts, vs/list/grid icons, username) rendered on all four game views; ComparisonView cleaned up with a red full-height Skip button beside the game cards and no nav buttons; and grid set as the default landing view. All automated tests (Header.test.tsx, ComparisonView.test.tsx, store.test.ts) and `npx tsc -b` pass.
  </what-built>
  <how-to-verify>
    1. Run `npm run dev` and open the app; log in with a BGG username that has ranked games.
    2. Confirm the app lands on the GRID view (10-wide thumbnail grid), NOT the comparison view (D-10).
    3. Confirm the header at top shows, left to right: ☰ hamburger · "{N} this session · {N} total" · ⚔ / ☰ / ⊞ icons · username. Confirm the grid (⊞) icon is highlighted (blue) as the active view.
    4. Click the ☰ hamburger; confirm the menu lists: Sync to BGG (N), Refresh rankings, Unplayed (N), Logout. Confirm "Unplayed" opens the unplayed list.
    5. Click the ⚔ icon → comparison view. Confirm: the same header renders (⚔ now highlighted); the two game cards sit side by side with a RED Skip button to their right that is the FULL height of the cards; there is NO "Ranked list / Grid view / Unplayed" button row below the cards; the amber upset callout (after a pick) appears between the cards row area as before.
    6. Click the ☰ (list) icon → ranked list, and confirm it has the universal header and NO "← Back" button. Repeat for the unplayed list.
    7. Confirm you can navigate freely between all four views using only the header (icons + hamburger) — no dead ends.
  </how-to-verify>
