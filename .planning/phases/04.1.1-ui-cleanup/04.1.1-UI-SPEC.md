## Spacing Scale

Declared values (must be multiples of 4) — matches existing codebase usage, not introducing new tokens:

| Token | Value | Usage in this phase |
|-------|-------|-------|
| xs | 4px | `gap-1` between grid thumbnails (unchanged); icon-to-label gaps in header |
| sm | 8px | Menu item vertical rhythm; view-switch icon button internal padding |
| md | 16px | Page horizontal padding (`px-4`, unchanged on all 4 views); default gaps between header sections |
| lg | 24px | `gap-6` between the two GameCards and the new Skip column (D-07) |
| xl | 32px | Page vertical padding (`py-8`, unchanged) |
| 2xl | 48px | not used this phase |
| 3xl | 64px | not used this phase |

Exceptions: `py-1.5` (6px, not a multiple of 4) is used throughout the existing button/menu-toggle styling (e.g. hamburger button, menu items, back buttons). This is a pre-existing project-wide convention, not introduced by this phase — carry it forward unchanged for visual consistency with untouched components (GameCard, SortableRow, UnplayedRow).

| Accent (10%) | `blue-600` (#2563EB) | Reserved for: (1) "Pick this game" primary CTA — unchanged; (2) focus/keyboard-nav outline rings (`outline-2 outline-offset-2 outline-blue-600`) on all interactive controls; (3) the **active view-switch icon** in the universal header (highlighted state — `text-blue-600 bg-blue-50 rounded`, vs. default `text-gray-700`) |
| Destructive | `red-500`/`600`/`700` (#EF4444/#DC2626/#B91C1C) | Reserved for: (1) existing "Mark as unplayed" ✕ buttons — unchanged; (2) the **new Skip button styling** (D-08) — reuses this exact red trio (`bg-red-500 hover:bg-red-600 active:bg-red-700 text-white`) |

Accent reserved for: "Pick this game" CTA, all `outline-blue-600` focus rings, active view-switch icon in the universal header. Never applied to body text or decorative elements.

**Note on Skip button color (D-08):** Skip is not a destructive/data-loss action, but the user explicitly locked red styling for it. This is a deliberate visual-weight decision (draw attention to the "opt out of this pair" action), not a semantic "danger" signal — flagged here so the checker doesn't misread it as a confirmation-dialog trigger.

Existing untouched semantic color (unchanged, D-09): `amber-50`/`amber-200`/`amber-800` for the `lastUpset` callout banner.

## Layout Contract (phase-specific, resolves CONTEXT.md discretion items)

**Universal header** — single component, renders identically on all 4 views (comparison, ranked-list, ranked-grid, unplayed-list), replacing every per-view header:

```
[☰ hamburger]   {sessionComparisons} this session · {comparisonsTotal} total   [⚔ vs] [☰ list] [⊞ grid]   {sessionUsername}
```

- Container: `flex justify-between items-center` wrapper, `text-base text-gray-700`, `mb-8` below (matches existing ComparisonView header spacing) — reused as-is for all 4 views (was previously ComparisonView-only).
- Hamburger dropdown: reuse existing state/timer pattern verbatim (`useState` + `useRef` timer, 150ms close delay on mouse-leave, `mouseenter`/`mouseleave` handlers) — do not reinvent.
- View-switch icon group: `flex gap-2` cluster of 3 buttons, each `px-3 py-1.5 rounded text-sm`; active view gets `text-blue-600 bg-blue-50`, inactive gets `text-gray-700 hover:bg-gray-50`.

**ComparisonView row layout (D-07/D-08):**

Change from `grid grid-cols-2 gap-6` to a 3-column stretch layout so Skip can match GameCard column height without a hardcoded pixel value:

```
grid grid-cols-[1fr_1fr_auto] items-stretch gap-6
```

- Columns 1–2: existing `GameCard` components, unchanged.
- Column 3: Skip button, `h-full px-6 bg-red-500 hover:bg-red-600 active:bg-red-700 text-white text-sm font-medium rounded outline-2 outline-offset-2 outline-red-600 flex items-center justify-center` — `h-full` on a CSS Grid `items-stretch` row automatically matches the tallest GameCard, no fixed height needed. Horizontal padding (`px-6`) stays the same as today's centered Skip button — width unchanged per D-08.
- `lastUpset` callout stays between this row and... actually stays between the cards and this row per D-09 (unchanged position — renders above the grid row, as it does today).

**Removed from ComparisonView (D-06):** the "☰ Ranked list", "⊞ Grid view", and "Unplayed (N)" buttons below the cards — fully replaced by the universal header's view-switch icons and hamburger's new "Unplayed" item.

**Removed from RankedListView, RankedGridView, UnplayedListView (D-04/D-05):** the standalone `<h1>` title + "← Back" header block — fully replaced by the universal header. `backToComparison()` store action is preserved, now wired to the header's ⚔ icon.

**Default view change (D-10/D-11):** all automatic `view: 'comparison'` transitions in `store.ts` (post-login/collection-load, post-sync, post-401-reset — lines ~257, ~293, ~539, ~554, ~569) become `view: 'ranked-grid'`. `backToComparison()` itself is unchanged (still sets `'comparison'` on demand, wired to the ⚔ icon click).
